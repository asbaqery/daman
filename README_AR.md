# ضمان 🛡️

ادفع لحسابات الإنستغرام والمشاريع المنزلية بأمان: المبلغ **ينحجز** على بطاقة المشتري، وما ينتقل للبائع إلا لما المشتري يأكد إنه استلم طلبه.
مشروع Day 6–8 في دورة Web with AI (ثيم FinTech). نسخة Day 7: تشتغل على **Replit** والبيانات في **MongoDB**.

- الكود: https://github.com/asbaqery/daman

## كيف يشتغل
1. البائع يسوي صفقة (المنتج والسعر) وياخذ رابط يرسله بالواتساب.
2. المشتري يفتح الرابط، يسوي حساب أو يسجل دخول، ويدفع بالبطاقة. **المبلغ ينحجز** بس (Stripe بوضع التجربة، `capture_method: manual`).
3. البائع يشوف «المبلغ محجوز» ويعلّم «تم الشحن».
4. المشتري يأكد الاستلام فينسحب المبلغ للبائع، أو يلغي قبل الشحن فينفك الحجز وما ينخصم شي.

## التقنيات
| الجزء | الأداة |
|---|---|
| الموقع والخادم | Next.js 16 (App Router) + TypeScript + Tailwind |
| البيانات | MongoDB Atlas (قاعدة `daman`) عن طريق Mongoose |
| تسجيل الدخول | bcrypt + JWT في كوكي `httpOnly` |
| الدفع | Stripe بوضع الاختبار، وWebhook موقّع على `/api/stripe/webhook` |
| النشر | Replit (Autoscale) |

## الأمان
- الجلسة في كوكي `httpOnly`، والتوكن ما يطلع للمتصفح.
- كل طلب POST يمر على فحص المصدر (CSRF).
- البائع والمشتري يجون من الجلسة على الخادم، مو من المتصفح. والسعر والحالة ما يقدر المتصفح يغيرها.
- حالة «المبلغ محجوز» تجي **بس** من Webhook موقّع من Stripe، مو من فتح رابط النجاح.
- الصفقة تنحجز لمشتري واحد وقت الدفع (35 دقيقة)، والدفع الزايد أو المتأخر ينفك حجزه تلقائيًا.
- صفحة الصفقة العامة ما تكشف أي بيانات عن البائع أو المشتري.
- كل الأسرار في Replit Secrets بس، ومفتاح Stripe لازم يكون `sk_test_`.

## العملة
حساب Stripe التجريبي ما يدعم الدينار، فالموقع يعرض بالدينار ويحصّل بالدولار بسعر ثابت: 1 د.ك = 3.25 دولار.

## المتغيرات (Replit Secrets)
| الاسم | سري؟ | الوصف |
|---|---|---|
| `MONGODB_URI` | نعم | رابط Atlas لقاعدة `daman` |
| `JWT_SECRET` | نعم | نص عشوائي 32 حرف أو أكثر |
| `STRIPE_SECRET_KEY` | نعم | مفتاح `sk_test_` |
| `STRIPE_WEBHOOK_SECRET` | نعم | `whsec_` من Webhook وضع الاختبار |
| `APP_ORIGIN` | لا | رابط الموقع المنشور، مثل `https://daman.replit.app` |

## التشغيل
```bash
npm install
npm run dev
npm test
```
على Replit: `.replit` يبني بـ `npm run build` (webpack) ويشغل بـ `npm run start`.

## Stripe Webhook
العنوان: `https://<رابط Replit>/api/stripe/webhook`، والأحداث: `checkout.session.completed` و`checkout.session.expired` و`payment_intent.canceled` و`payment_intent.succeeded`.

## حدود معروفة
- البنك يحجز المبلغ 7 أيام تقريبًا. إذا ما تأكد الاستلام خلالها، الحجز ينفك والصفقة تصير «انتهت مدة الحجز».
- النزاعات وتحويل المبلغ لحساب البائع البنكي في «الرؤية»، مو في الـMVP.
- حساب Stripe التجريبي مشترك مع مشاريع ثانية، والـWebhook يتجاهل أي حدث مو لصفقة من «ضمان».
